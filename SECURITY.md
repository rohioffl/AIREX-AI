# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | yes       |

## Reporting a Vulnerability

AIREX is a live production system. Please **do not** open a public GitHub issue for security vulnerabilities.

**Contact:** security@ankercloud.com

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We aim to respond within **48 hours** and will coordinate a fix and responsible disclosure timeline with you.

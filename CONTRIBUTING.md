# Contributing

AIREX is a proprietary project maintained internally at Ankercloud. External contributions are not currently accepted.

## Internal Development

- Branch naming: `feat/`, `fix/`, `chore/`, `docs/`
- All PRs must pass the CI suite (525 backend tests + 165 frontend tests)
- Use `ruff` for linting and `mypy` for type checking
- Run `pytest` from the `tests/` directory before opening a PR

## Reporting Issues

Use the GitHub Issue templates for bug reports and feature requests.
